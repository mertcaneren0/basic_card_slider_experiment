# Basic Card Slider Experiment

A profile card slider built with Swiper.js.

## What it demonstrates
- Using a third-party slider library (Swiper) from a CDN
- Card layout with an image, social icons, star rating and buttons
- Looping slider with navigation arrows and pagination

## Features
- Shows 3 cards at a time and moves 3 cards per step
- Infinite loop
- Next/previous arrows and clickable pagination dots
- All cards use the same sample content; the buttons are for show only

## Tech
- HTML, CSS, JavaScript
- Swiper.js and Font Awesome (from CDN)

## How to run
Open `index.html` in your browser (it needs an internet connection for the CDN files).
